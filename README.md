# United Kingdom — Geographical Position
Mini website by **Serzhan Birzhan**, group **APE2601**.

- `index.html`, `style.css`, `script.js` — site (HTML / CSS / JavaScript, sounds via Web Audio)
- `main.cpp` — C++ program that generates `data.js` (map outline, cities, facts)
- Rebuild data: `g++ main.cpp -o gen && ./gen > data.js`

Publish: GitHub → Settings → Pages → Deploy from branch `main` / root.
